# WebsiteViewer

WebsiteViewer 是一个 Windows 网站结构扫描工具，用来快速统计一个官网实际可发现的页面数量，并查看栏目、URL 层级、父子关系和页面响应性能。

当前版本：**v0.0.4**

## v0.0.4 深色 UI 修复

- 原生 WinForms `TabControl` 未绘制的区域会出现系统浅灰/白底，现已用全自绘深色标签条及普通面板切换代替，去除系统边框与白色条带。
- 页面列表与栏目统计统一取消系统 Raised 表头边线及原生网格边线，避免在深色界面出现亮白分割线。
- 搜索框、URL、输出路径及页面详情框全部采用无原生边框的深色输入框宿主容器，四周不再出现浅色描边，文字保持垂直居中。
- 保留 v0.0.3 的批量 UI 刷新、虚拟表格、深色圆角卡片，以及栏目、结构树、运行日志和 CSV/JSON 导出能力。


## 主要功能

- 从指定首页开始发现站内页面，找到一页就实时显示一页。
- 页面列表显示 HTTP 状态、深度、栏目、请求耗时、HTML 解析耗时、标题和 URL。
- 栏目统计显示每个一级栏目对应的页面数量、成功数、失败数和占比。
- 结构树按域名和 URL 路径展示父子层级，可选择任意分支筛选页面列表。
- 页面详情区展示推断父级 URL、发现来源、Canonical 或错误信息。
- 实时显示已扫描、成功/失败、发现/队列、扫描速度、运行时间、ETA、平均请求和平均解析耗时。
- 支持停止扫描并保留当前结果。
- 支持导出 `urls.csv`、`edges.csv`、`section_counts.csv`、`tree.json`、`summary.json`。
- 支持遵守 `robots.txt`、忽略 URL Query、包含子域名、自定义并发/深度/请求间隔。

## UI

界面延续 v0.0.2 的深色卡片式设计，并在 v0.0.4 重点修正布局稳定性：

- 目标网址与“开始扫描 / 停止扫描”使用独立网格单元，按钮不会互相覆盖。
- 四个数字参数固定为等宽自适应网格；三个开关固定在下一行，不依赖 FlowLayout 自动换行。
- 主工作区保持 `页面列表 / 栏目统计 / 结构树 / 运行日志` 标签页。
- 900px 宽度下统计卡保持 4×2；宽屏才切换为 8×1，不会为了节省高度强行挤压文字。
- 使用 `PerMonitorV2` 高 DPI 模式和 Microsoft YaHei UI 字体。
- 页面列表采用虚拟模式，避免页面数量上升后表格本身成为主要性能瓶颈。

## v0.0.4 性能与布局修复

- 页面结果改为 DataGridView 虚拟模式，大量页面时不再为每个单元格持续创建 UI 对象。
- 扫描线程不再“每发现一页就 BeginInvoke 一次”；页面、进度和日志统一进入队列，由 UI 每 100ms 小批量刷新。
- 运行日志改为批量追加，结构树只在打开“结构树”页时增量同步，栏目统计只在需要显示时刷新。
- 搜索筛选增加 250ms 防抖，窗口 Resize 只在响应式布局模式实际变化时重排。
- “开始扫描 / 停止扫描”改为独立等宽操作区，修复按钮边缘、禁用状态和窗口缩放时的异常显示。
- 参数区取消 `AutoSize FlowLayoutPanel`，改成固定两层自适应网格；`忽略 URL 参数 / 遵守 robots.txt / 包含子域名` 三项不会再互相覆盖。
- 窄窗口不再为了节省高度强行把 8 个统计卡挤成一排，900px 宽度下保持 4×2。

双击：

```text

```


## 扫描结果说明

WebsiteViewer 通过服务器返回 HTML 中的站内链接继续发现页面，不执行页面 JavaScript。因此纯前端运行后生成的链接、登录后页面、没有任何站内入口的孤立页面等可能不会被发现。

因此页面总数应理解为：**从指定入口、按当前扫描规则实际可发现的页面集合**，而不是服务器内部全部路由的绝对数量。

请控制并发和请求间隔，并遵守目标站点的使用政策、`robots.txt` 和适用规则。
